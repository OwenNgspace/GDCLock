GitHub Pages 部署指南

按照以下步骤将你的网页成功部署到GitHub Pages

步骤 1: 创建GitHub仓库

仓库名称必须遵循特定格式：你的用户名.github.io

例如，如果您的用户名是"johnsmith"，那么仓库名应该是"johnsmith.github.io"

步骤 2: 准备你的文件

确保你的HTML文件名为index.html，并且位于仓库的根目录

你的文件夹结构应该类似这样：

my-website/
└── index.html

步骤 3: 上传文件到GitHub

使用以下Git命令上传你的文件：

git init
git add .
git commit -m "First commit"
git branch -M main
git remote add origin https://github.com/你的用户名/你的用户名.github.io.git
git push -u origin main

步骤 4: 启用GitHub Pages

1. 转到你的GitHub仓库页面

2. 点击"Settings"选项卡

3. 在左侧边栏中选择"Pages"

4. 在"Source"部分，选择"main"分支

5. 点击"Save"按钮

提示：部署可能需要几分钟时间。如果第一次访问显示404，请等待5-10分钟再试。

注意：确保你的仓库是公开的(Public)，而不是私有的(Private)，否则GitHub Pages无法工作。

完成以上步骤后，你的网站应该可以通过以下网址访问：

https://你的用户名.github.io
